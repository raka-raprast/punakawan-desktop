# Punakawan interface

The product uses a compact editing workbench: document and layer rails surround a blank, unbounded dotted canvas. There is no fixed artboard; users draw white custom frames to organize shapes and can leave other objects free-floating outside frames. The welcome screen is a separate entry point; once a file opens, tools, pages, canvas, and properties stay in predictable locations.

- **Color:** Quiet neutral paper and ink, cobalt for primary actions, selected tabs/canvases, outlines, handles, and live drawing feedback. Light, dark, and system-following themes switch foreground and surface tokens together so labels and inputs retain contrast. Frames remain white in both appearances; unframed export areas are transparent. Dragging an empty canvas with Select draws a translucent cobalt selection box; selection applies to objects only after pointer release. Drawing and resizing objects retain their actual fills.
- **Type:** Compact system-backed sans for controls; larger, heavier display type only on the welcome screen. Measurements and counts use tabular numerals.
- **Layout:** Persistent 65px top bar, 39px document tabs, 228px page/layer rail, flexible canvas, 254px property rail, and slim status strip. Below narrower desktop widths, tool labels collapse while accessible button names remain available.
- **Panel resizing:** Both rails resize from their canvas-facing dividers, retaining their original 228 px and 254 px minimums; a narrow window scrolls the workspace horizontally rather than crushing the panels.
- **Controls:** Small rounded utility controls, default square-cornered editable frames, hairline divisions, and visible focus rings. The frame tool sits beside the shape menu (rectangle, line, arrow, ellipse, polygon, star, and image import); text remains one click away. Layers nests contained objects beneath collapsible frames and Boolean groups, with nested groups and operand selection available in the same tree. Edge hit targets make even unfilled shapes selectable; eight handles allow directional resizing. Pan/zoom controls, multi-selection, layer ordering, undo/redo, and context menus are available without entering a mode. Selected tool, canvas, tab, and layer share cobalt-tinted states. File-saving and recovery errors surface in the status strip, not as silent failures.
- **Object fidelity:** Nearby rounded dimensions snap while Alt-drag retains fractional sizing. The inspector exposes borders, opacity, corner radius (together or per corner), and text alignment, line height, and letter spacing. Text controls precede appearance controls and expose installed font families with their available weight/italic/oblique styles. Names edit directly above canvas objects or in Layers; new text receives typing focus and empty text disappears. Click-created text grows horizontally in Auto width until its width is manually constrained; side handles use Auto height, while drawn boxes and corner/vertical resizing use Fixed size. Text wraps without scaling its font, and fixed text may overflow its box. The resizing selector lets users return to automatic sizing. On canvas, selecting a character range inside an editing text object restyles only that range — font, style, size, fill, and letter spacing — rendered as per-character spans in both the live editor and the exported SVG/PNG; the inspector reports "Mixed" per field when a selection spans differing values. Resized images retain their source aspect ratio and crop inside rounded bounds. Export uses the same styling and geometry.
- **Transform controls:** Images start with a locked aspect ratio, including edge-handle resizing and numeric dimension edits; Shift temporarily inverts the lock. Selected non-frame objects expose separate corner rotation hit zones outside their square resize handles, a rotate cursor, 15° Shift snapping, and a numeric rotation field. Canvas selection and export retain the transformed geometry.
- **Boolean operations:** With multiple compatible vector shapes selected, the inspector header changes to a compact count with a last-used operation button, duplicate action, chevron, and overflow action. The chevron opens a floating menu with Boolean icons, labels, shortcut hints, and Ungroup when a group is selected, using the workbench's light/dark surfaces and cobalt focus state. Union, Subtract, Intersect, and Exclude preserve their operands as children of a collapsible Boolean group; a cached normalized path draws only the resulting silhouette. Merges can be canceled at any time by ungrouping, which releases child shapes back to their parent container and dissolves the group. Double-clicking the result selects a component and overlays editable operand outlines; Escape returns to the group. Editing a child recomputes parent and nested group paths bottom-up, including recovery from an empty intersection. Moving, resizing, rotating, duplicating, deleting, saving/reopening, and undoing a group keep its operand tree coherent. SVG/PNG page, frame, and group exports draw the silhouette once; selecting a child exports that shape alone. Flatten is deliberately destructive: it converts compatible selection geometry to one independent vector and removes source operands. Initially incompatible content-bearing or styled selections remain disabled.
- **Object state and orientation:** Layer rows reveal eye and lock buttons on hover and keep them visible once on; hidden rows are dimmed, locked shapes show no resize or rotate handles. The context menu and inspector share one icon row for Rotate 90°, Flip horizontal, Flip vertical, Hide, and Lock, with shortcut hints.
- **Property sections:** Stroke, Effects, and Export are flat sections divided by a hairline, each titled at left with a quiet **+** at right. Stroke shows a swatch, hex, and opacity field with eye and minus actions, then Position and Weight; Position, effect type, export scale, and format use a dark popover list with a check beside the current choice and cobalt highlight for the focused row. The Effects **+** opens an icon list (Inner shadow through Glass) aligned to the right edge. Effect rows show only the parameters of their type; export rows pair scale, suffix, and format above a primary Export button.
- **Text on a path:** The text tool offers a dropdown submenu providing both standard text and Text on path. Selecting Text on path attaches to an already selected vector host or primes the canvas cursor to attach on the next clicked shape. SVG textPath displays a live curved preview during text editing, with dual `href` and `xlink:href` references for robust WebKit rendering; the inspector offers offset, reverse direction, and detach. The linked text follows host resizing/rotation and survives file serialization and export.
- **Motion:** Short state transitions on controls; no decorative canvas animation. Reduced-motion clients receive the same information without relying on movement.

The app icon echoes stacked sheets and editable frames, using the same ink/paper/cobalt roles.
