# Punakawan

Local-first design editor built with **Tauri 2, React, and TypeScript**. Files use the portable `.punakawan` JSON format; images are embedded as data so moving a design file does not break its assets.

## Run

Install Node.js and the Rust stable toolchain, then:

```sh
npm install
npm run tauri -- dev
```

Build a desktop binary with `npm run tauri -- build` (or `npm run tauri -- build --no-bundle` for a local binary). On macOS, `npm run tauri -- build --bundles app` refreshes `src-tauri/target/release/bundle/macos/Punakawan.app`. `npm run build` updates only the browser assets in `dist`; it does not update an already bundled desktop app. Quit and reopen the rebuilt app to see frontend changes. `npm run dev` starts a browser **preview only**; native file dialogs, disk storage, fonts, and recovery require the Tauri desktop app.

## Workflows

- **New / Open:** Use the welcome screen, tab `+`, or shortcuts. Recent files appear on the welcome screen. Each open design has its own tab.
- **Edit:** New designs open on a blank, unbounded canvas named Canvas; there is no preset artboard. Press F or use the Frame tool to draw a custom-sized white frame (click for 480 × 320 px). Use the shape menu for rectangle, line, arrow, ellipse, polygon, and star; text and image import remain separate tools. Drag anywhere or click for a default-sized object. Objects fully inside a frame appear beneath it in Layers; objects outside stay at the top level. Drag an object into or out of a frame to change its parent. Moving a frame moves its children; resizing a frame changes only its bounds. Select by clicking an object or its edge; use eight handles to resize (Shift on a corner preserves proportions). Drawn and resized dimensions snap near multiples of 10 px, round to whole pixels elsewhere, or retain tenths with Alt-drag. Shift-click or drag across objects to select multiple objects. The inspector accepts negative coordinates. Click a frame or selected object's canvas label, or a layer name, to rename it inline. Add, duplicate, rename, and delete canvases from the Pages rail.
- **Panel sizing and rotation:** Drag either divider between the canvas and a sidebar to widen its panel; the left and right panels stop shrinking at 228 px and 254 px respectively. Select a non-frame object, hover just outside a selection corner (not on its square resize handle) for the rotate cursor, then drag to rotate around its center. Hold Shift during rotation to snap to 15° increments. The Rotation field accepts precise degrees. Fit view and SVG/PNG export include the rotated footprint.
- **Style:** With Select active, drag on empty canvas to draw a tinted selection box; objects are highlighted only after selection. Drawing and resizing objects leave their actual fills unchanged. The inspector edits fill, border color and width, opacity, and uniform or independent corner radii on supported shapes and frames.
- **Boolean shapes:** Select two or more filled rectangles, ellipses, polygons, stars, existing vectors, or Boolean groups. The inspector Boolean menu offers Union, Subtract, Intersect, Exclude, and Flatten; the main button repeats the last operation. Subtract cuts higher shapes from the bottommost selected shape; all operations use canvas order. Union/Subtract/Intersect/Exclude create a non-destructive Boolean group: expand it in Layers to select its original shapes, or double-click its canvas result to select a component and edit it with handles or the inspector. Press Escape to return to the group. Changes to components update the result, and even an empty intersection keeps its components for later editing. To cancel the merge and restore the original independent shapes, use **Ungroup** in the inspector, context menu, or via ⌥⇧G/⌘⇧G. Move, resize, rotate, duplicate, undo/redo, save/reopen, and export the group as one visible silhouette; selecting a component exports it on its own. **Flatten** (also available for a single shape) makes a standalone vector and discards its operands. Shortcuts are ⌥⇧U/S/I/E/F respectively and can be changed in Preferences. Operations initially reject text, images, frames, open lines/arrows, visible strokes, partial opacity, and shapes with attached text; Flatten also requires matching fills.
- **Hide, lock, flip, rotate:** Each Layers row has an eye and a lock button. Hidden shapes (and their descendants) are not drawn, hit-tested, or exported; locked shapes stay in Layers but cannot be selected on canvas, moved, resized, rotated, or deleted. The canvas/Layers context menu and inspector offer Rotate 90° (⌥⇧R), Flip horizontal (⇧H), Flip vertical (⇧V), Show/Hide (⌘⇧H), and Lock/Unlock (⌘⇧L); multiple selections turn around their shared center. Flips are real mirrors that persist in the file, export to SVG/PNG, and apply inside Boolean geometry.
- **Stroke, Effects, Export:** The inspector has three sections, each with a **+** header button. **Stroke** adds one stroke with color, opacity, weight, and Position (Center, Inside, Outside) on closed shapes and frames; the eye hides it without losing its settings and **−** removes it. **Effects** opens a menu of Inner shadow, Drop shadow, Layer blur, Background blur, Noise, Texture, and Glass; add as many as you like, each with its own parameters, an eye, and **−**. Shadows keep their screen direction when a shape is rotated or flipped. Background blur and Glass blur the artwork painted below the shape, clipped to its outline (Glass adds magnification, an RGB split, and an edge highlight — an approximation, not a physical refraction model). Noise and Texture are clipped to the shape; they use a generated pattern, so exact grain differs between renderers. **Export** lists per-object settings (scale 0.5x–4x, suffix, PNG/JPG/SVG); **Export <name>** writes one file with a save dialog, or all settings into a chosen folder (`Name.png`, `Name@2x.png`, …). Exports include shadow and outside-stroke overflow, JPG has a white background, and shapes with a visible stroke or effect cannot join Boolean groups. Shader (beta) is not included.
- **Text:** Click with the Text tool to type in **Auto width**: the text grows horizontally as you type, and Enter adds an explicit line break. Drag with the Text tool to create a fixed-size text box instead. Double-click existing text to edit it on canvas; leaving it empty removes it. Drag a left/right handle or edit Width to wrap text at that width with **Auto height** (an already fixed-size box stays fixed). Drag a corner/top/bottom handle or edit Height to use **Fixed size**; text wraps without scaling the font and can overflow below the box. Switch back to Auto width, Auto height, or Fixed size in the inspector. Choose an installed font family and its available weight/italic/oblique styles, plus size, alignment, line height, and letter spacing. Generic sans-serif, serif, and monospace families are also available. While editing on canvas, select a character range to restyle just that selection — font family, style, size, color, and letter spacing apply only to the selected characters; the inspector shows "Mixed" where the selection holds more than one value, and a collapsed caret (no selection) still edits the whole object's defaults. Each line grows to fit its tallest character so a larger run never gets clipped by its own object's box; setting an explicit line height instead applies that value to every line uniformly, even if a larger run then overflows it. Sizing, font style, and per-character styling all survive undo/redo, saving, and SVG/PNG export; older text objects retain their existing width and wrapping.
- **Text on a path:** Click the chevron next to the Text tool in the toolbar to open the Text dropdown menu and choose **Text on path** (Shift+T). If a line, arrow, rectangle, ellipse, polygon, or star is already selected, it attaches immediately; otherwise, click the vector host on canvas. Type directly in the focused editor; curved text displays live along the path as host geometry, corner radii, or rotation changes. Double-click the text on canvas to re-edit. Select the text to adjust Start offset %, toggle path reversal, or click Detach from path to turn it back into normal text. Linked text and its styling persist in `.punakawan` files and SVG/PNG exports.
- **Navigate:** Use the Hand tool, hold Space and drag, or middle-drag to pan. Wheel gestures pan; Ctrl/⌘ + wheel zooms toward the cursor. The toolbar also provides zoom in/out, 100%, and Fit content.
- **Commands:** Delete or Backspace removes selected objects; deleting a frame or Boolean group also removes its descendants. Arrow keys nudge by 1 px (Shift + arrow: 10 px). Mod+Z undoes, Mod+Shift+Z redoes, Mod+D duplicates, Mod+C/V copies and pastes within the editor, and Mod+A selects visible objects on the canvas. Duplicating or copying a frame or Boolean group includes its children. Right-click the canvas to add a frame or object, or paste at the pointer; right-click a shape to copy, duplicate, reorder, or delete it.
- **Save:** Save chooses a file the first time; Save as chooses a new location. Saved files autosave after an editing pause when enabled in Preferences. Unsaved designs retain recovery copies. The title, canvases, frames, shapes, and embedded images are stored together in one `.punakawan` file; existing files remain readable.
- **Images and export:** Import PNG, JPEG, GIF, WebP, or safe SVG via the toolbar or shape menu. Images fill their bounds with a centered crop when resized rather than stretching; the embedded original remains unchanged. Rounded corners, borders, and opacity appear in SVG and PNG exports. Export the bounds of all visible canvas objects or one selected object as SVG or PNG. A selected frame includes its visible children; a Boolean group exports its combined silhouette without drawing its hidden operands a second time. An empty canvas exports as a transparent 1 × 1 image. Unframed areas remain transparent. Text uses installed local fonts; a font must also be installed on another machine to render the same way there.
- **Image proportions:** Imported images start with **Lock aspect ratio** on. The inspector lock toggles proportional sizing for both Width/Height fields and canvas edge/corner handles. Hold Shift during a resize to temporarily invert the current lock state; unlocking permits independent crop dimensions.
- **Preferences:** Appearance, autosave, and editable keyboard shortcuts live under the top-right settings control. Conflicting and reserved system shortcuts are rejected.
- **Recovery:** The app offers recoverable drafts on the next launch after an interrupted session. Restore to a tab and save, or discard a copy. Closing a dirty tab asks whether to save or discard; a normal window close flushes pending saves/recovery.

## Verify

```sh
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
```

State and recovery files reside in the OS application-data directory under `com.punakawan.design`. Designs and exported images are written only to locations selected by the user. Collaboration and Figma file compatibility are not part of this local file format.
